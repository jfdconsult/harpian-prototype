03 Alignment Logic — How It Works
01
Client completes Risk Intake questionnaire 20–30 behavioral questions → scored → outputs RN Individual (0–99). Covers loss aversion, time horizon sensitivity, volatility comfort, wealth dependency.
02
Family Office intake (conditional) If FO exists → FO completes separate governance questionnaire → outputs RN Family Office. If no FO → system defaults to individual mandate only.
OptionalCreates institutional floor
03
Portfolio upload + parsing Client uploads current portfolio (Excel, PDF, HTML). Engine parses: asset class, country, currency, liquidity bucket, % allocation per position.
Formats: .xlsx / .pdf / .html
04
Engine calculates RN Portfolio Current Weighted sum of risk scores by position × allocation weight. Applies dimension multipliers: volatility, concentration, country, liquidity, correlation.
Blended RN = Σ(weight_i × RN_i)
05
Engine calculates RN Requirement Based on: target capital, current capital, time horizon → backwards-solved return rate needed → translated to minimum RN required.
Reverse-engineers required risk from goal
06
Gap analysis — 4 comparisons run simultaneously · RN Portfolio vs RN Individual (behavioral alignment)
· RN Portfolio vs RN Requirement (goal feasibility gap)
· RN Individual vs RN Capacity (financial vs behavioral gap)
· RN Portfolio vs RN FO (institutional compliance)
All 4 gaps displayed as signed deltas
07
Engine runs allocation optimizer Finds optimal Core 11 % + Core 22 % to close the gap with minimum added risk. Subject to: RN constraint, max allocation rules, client tolerance.
08
Output: Dashboard + Recommendation + Simulator All RNs displayed simultaneously. Alignment state labeled. Recommendation card shows % suggestion. Simulator available for manual override and what-if testing.
Real-time recalculation on slider move

RN_blend = (w_existing × RN_portfolio) + (w_C11 × RN_C11) + (w_C22 × RN_C22)

06 Alignment States Matrix
Fully Aligned
Portfolio RN within target zone. All gaps within ±5 pts. Goal feasibility ≥80%.
→ Maintain current structure
Moderate Mismatch
Portfolio RN within 5–15 pts of target zone boundary. Some gaps outside tolerance.
→ Suggest rebalancing to Harpian products
Over-Risked
RN Portfolio > RN Individual + 15 pts. Behavioral tolerance breach. Action required.
→ Reduce equity/concentration. Add Core 11.
Under-Risked
RN Portfolio < RN Requirement − 10 pts. Goal infeasible at current risk level.
→ Add Core 22. Extend horizon. Revise target.
Goal Infeasible
Even at max tolerance RN, return requirement cannot be met within stated horizon.
→ Revise target, extend horizon, or increase capital
High Appetite / Low Capacity
Client wants more risk than their financial situation can absorb. Structural conflict.
→ Cap at RN Capacity. Document conflict.
Low Appetite / High Requirement
Goal requires more risk than client is behaviorally willing to accept.
→ Educate on risk-return. Revise goal or horizon.
FO Ceiling Breach
Simulated or current RN exceeds Family Office institutional mandate ceiling.
→ Hard cap at RN FO. Alert advisor.

10 Developer Visual Priorities
⚡
5-second legibility rule User must understand alignment status in 5 seconds without reading any text. Status color, hexagon shape, and banner label carry this.
⟷
Sliders → instant update All 7 output metrics recalculate and animate in <100ms from slider release. No loading states. This is the product's core interaction.
◈
Hexagon = portfolio identity The radar chart shape is the visual fingerprint of a portfolio. It must morph with CSS/SVG transition on change. Not a chart — it's an attribute profile.
◫
Recommendation card always visible The AI recommendation card must not be hidden behind scroll or collapsed by default. It is the primary output. Sticky if needed.
◱
Before vs After must be unmissable The current vs simulated comparison cannot be subtle. High contrast, delta badges in ↑ green / ↓ red, large numbers. Zero ambiguity.
≡
No long text anywhere in the UI Every insight must be expressed in ≤15 words or a number. Long explanations are for the PDF export — not the interface.
◙
Institutional dark premium — not gamified Colors: Navy, Gold, White. Fonts: geometric sans + mono. No gradients, no neon. Engineering dashboard feel. Think Bloomberg terminal with better UX.
⬡
Hexagon vs bar — deliberate usage Hexagon = portfolio personality (6D). Bars = relative magnitude comparison (RN rails). Never mix the semantics. Each visualization has a single job.
▣
Color = signal, not decoration Green = aligned. Amber = warning. Red = action required. Blue = under-risked. Purple = structural conflict. Gold = Harpian product. Every color has a fixed meaning.
⊞
Grid precision All spacing, card sizing, and alignment on an 8px grid. No visual entropy. The interface communicates precision because it is precise.
